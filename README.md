简易Knn算法，对单数字进行预测，带有训练集。

- 内存消耗：约8.5MB训练数据，20KB栈占用。
- 数值判断过程
    1. **逐张比较**：把新图和训练图逐个对比，算出每个像素点差值，也就是“距离”，并将它们求和，值越小，则两张图越像。
    2. **按距离排序**：把所有图对比距离从小到大排好，排在最前面的就是最像的。
    3. **取前 K 张投票**：看最像的 K 张训练图各自是数字几，哪个数字票数最多，新图就判成几。
- 无负反馈训练，因此测试集只进行准确率打分，不参与修正。
